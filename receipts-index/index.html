Data-Lease Feed for Agents

Some feed endpoints on this domain are gated. An agent or a person that requests a gated path gets back an HTTP 402 response, the status code reserved for payment required. The payment terms live in a Base64 encoded PAYMENT-REQUIRED response header, the current x402 protocol's own wire format for this response. The same terms also print below as plain JSON, readable by any agent or person, describing what the endpoint would need before it serves data.

Nothing in that response arms a live payment. Every field that would need a real network, asset, payTo address, or account reads the literal string TBD-NOT-ARMED, on purpose, so no client that finds this route and tries can be charged.
