About This Page

This dashboard is built once, from files read at the timestamp in the banner above. It is not a live socket and does not poll any server after it is saved. Every number carries the file it came from and the timestamp on that file.

Void and dark organ counts are printed at the same size and weight as the ok count. A missing module or an unparsed ledger line is reported as a count, not hidden. This page makes no income claims and offers no guarantees about future results.
